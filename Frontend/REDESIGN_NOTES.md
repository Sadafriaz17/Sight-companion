# Sight Companion frontend redesign

This frontend uses a responsive accessibility-first navigation-console layout. The application behavior and API contracts are unchanged.

The visual system uses an ink sidebar, warm paper canvas, cyan live state, lime active navigation, amber caution state, and coral danger state. Desktop uses a fixed navigation rail with a split camera/Lumi workspace. Mobile collapses to a bottom navigation bar with a stacked camera and assistant layout.

The frontend folder is ready to paste over the original `Frontend/` directory. Install dependencies with `npm ci`, then run `npm run dev` or `npm run build`.
